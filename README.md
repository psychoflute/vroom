# Vroom
Vroom is a source-port for Doom & Doom II. Forked from doomgeneric, Vroom is extremely bare-bones at the moment.

## Setup
Using Vroom is as simple as it gets!

1. Compile using your preferred C compiler (Make, GCC, or Clang.)
2. Ensure you have the SDL2 development library.
3. Same with every source-port, you need an IWAD to play. You can get one at https://freedoom.github.io

## How to launch Vroom
If you have completed the checklist above, you should be ready to use Vroom!
Just run 'vroom -iwad path/to/your/iwad' to start playing!
